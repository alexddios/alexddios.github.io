Sobre mí

Quién soy y por qué programo

Hola, soy Álex De Dios, estudiante de primer año del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma. Elegí DAM porque desde pequeño me ha gustado entender cómo funcionan las cosas por dentro, y el software me pareció el reto perfecto.

Este primer año ha sido intenso: aprender a pensar en objetos con Java, diseñar bases de datos desde cero, entender por qué Git existe (y agradecerlo mucho), y darme cuenta de que la programación tiene mucho más que código. Me ha gustado especialmente todo lo relacionado con bases de datos y la programación orientada a objetos.

Busco unas prácticas donde poder aprender de profesionales con experiencia, contribuir en proyectos reales aunque sea en tareas pequeñas, y seguir creciendo como desarrollador. No tengo todo el camino claro, pero sí tengo muchas ganas.

// Proyectos académicos de 1º DAM. Pequeños pero bien documentados.

Gestión de Biblioteca
Proyecto académico · Java · Consola

Aplicación de consola en Java para gestionar libros, usuarios y préstamos. CRUD completo implementado con POO, herencia (Libro y Revista extienden Publicacion) y persistencia en ficheros de texto.

"Aprendí cómo la herencia hace el código mucho más organizado, y lo importante que es separar responsabilidades desde el principio."

Java SE POO Herencia Ficheros
BD Tienda Online
Proyecto académico · MySQL · Bases de datos

Diseño completo de base de datos relacional para una tienda online. Modelo ER, implementación en MySQL con DDL, consultas DML complejas, vistas y procedimientos almacenados básicos. Documentado con diagramas.

"Entendí que diseñar bien la base de datos al principio ahorra muchísimos problemas después. Las claves foráneas son tus amigas."

MySQL SQL DDL/DML Diseño ER Vistas
Catálogo de Películas
Proyecto personal · Java + SQLite · JDBC

Aplicación Java que se conecta a una base de datos SQLite mediante JDBC. Permite añadir, buscar y filtrar películas por género o año. Primer proyecto donde separé la lógica de datos de la lógica de negocio.

"Mi primer contacto real con JDBC. Me costó configurar la conexión, pero cuando funcionó fue muy satisfactorio. Aprendí que siempre hay que cerrar los recursos."

Java SE SQLite JDBC
